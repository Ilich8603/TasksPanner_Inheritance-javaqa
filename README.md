# Task Planner

Планировщик задач на Java с использованием наследования и полиморфизма.

## Типы задач

| Класс | Поля | Совпадение в `matches(query)` |
|-------|------|-------------------------------|
| `Task` | `id` | базовая логика (по умолчанию `false`) |
| `SimpleTask` | `id`, `title` | `query` в `title` |
| `Epic` | `id`, `subtasks[]` | `query` хотя бы в одной подзадаче |
| `Meeting` | `id`, `topic`, `project`, `start` | `query` в `topic` или `project` |

Все задачи **неизменяемы**: поля задаются в конструкторе, сеттеров нет — только геттеры.

## Менеджер `Todos`

- Хранит все задачи в одном массиве `Task[]`.
- `add(Task task)` — добавить задачу.
- `findAll()` — вернуть все задачи.
- `search(String query)` — вернуть задачи, подходящие под запрос (полиморфный вызов `task.matches`).
